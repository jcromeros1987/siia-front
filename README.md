# CVU

Frontend del perfil académico (SIIA / CVU SECIHTI).

## Requisitos

- [Node.js](https://nodejs.org) (incluye `npm`). Tras instalarlo, cierra y vuelve a abrir la terminal.

Las dependencias (`node_modules`) **no se versionan**. Hay que instalarlas en cada máquina después de clonar el proyecto.

## Instalar y levantar

Desde la raíz de este repositorio:

```bash
cd json-viewer-front
npm install
npm run dev
```

La app queda disponible en:

**http://localhost:8888**
